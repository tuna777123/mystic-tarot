# Mystic Tarot 1.10.2 — Five-language trust pages

Mystic Tarot now provides public privacy, terms, and support information in every launch-ready language:

- English
- Turkish
- French
- neutral international Spanish
- Brazilian Portuguese

Spanish and Brazilian Portuguese users no longer fall back to English for subscription, local-data, deletion, refund, sensitive-data, wellbeing, or emergency-support information. The generic support entry point routes supported browser languages to the matching page while preserving an explicit English choice.

Automated release checks verify all 15 trust pages, their HTML language declarations, localized internal links, support routing, and sitemap coverage.

Version: `1.10.2+16`
