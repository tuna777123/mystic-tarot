# Mystic Tarot 1.10.3 — Private memory integrity

This release packages the latest product and reliability work into one verified build.

## Mystic Mirror

- completes the free 24-hour reflection loop
- records outcomes, current emotion, and an optional private note
- keeps a last-known-good local backup before replacing Mirror data
- recovers safely from a damaged primary snapshot
- preserves valid reflections when one record is corrupt

## Living Journal

- removes the silent 50-reading history limit
- stores the complete reading history in a versioned local-first journal
- preserves a last-known-good backup before each replacement
- migrates existing journal data automatically
- rejects damaged or duplicate records individually instead of losing the full journal
- shows a recovery notice when backup data is used

## Five-language trust experience

- supports English, Turkish, Spanish, French, and Brazilian Portuguese
- routes the public support entry to the matching browser language
- preserves an explicit English choice
- exposes all five language choices on every support page

## Accessibility and release safety

- respects the operating system Reduce Motion preference
- cancels delayed reveal timers safely
- validates permanent store identifiers and signing configuration
- keeps subscriptions restricted to verified monthly and yearly store products
