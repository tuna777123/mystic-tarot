# Mystic Tarot — Competitive Moat

Mystic should not try to win a feature-count race against broad tarot, astrology, advisor-marketplace or generic AI products.

The product moat is a repeated private evidence loop:

**Reading → 24-hour reality check → accumulated personal evidence → explainable pattern memory.**

Product decisions should strengthen at least one of these assets:

- return reason;
- honest reality check;
- private longitudinal evidence;
- explainable personal pattern;
- trust/local-first privacy;
- earned, privacy-safe distribution.

A feature that does not strengthen the moat needs a measurable growth, reliability or monetization hypothesis before it earns roadmap priority.
