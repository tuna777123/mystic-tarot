# Category Leader Copy Guide

Use these phrases consistently in launch-facing and retention-critical UI.

## Core promise

- Read today. Check reality tomorrow.
- Your reading isn’t finished yet.
- One card is a reading. Repetition is a pattern.

## Grounding language

Prefer:
- reflection
- symbolic lens
- grounded action
- reality check
- private evidence
- recurring pattern

Avoid:
- guaranteed outcome
- prediction score
- proof that tarot was right
- diagnosis
- certainty about future events

## Ad trust

When ad-supported status is surfaced, keep it factual and quiet: core reflection features are not ad-gated; native ads are sparse and consent-aware; public web is ad-free.
