# Category Leader Pass — Implementation Scope

This pass converts the category-leader standard into a release-scoped implementation checklist.

## In scope

- onboarding differentiation: make the 24-hour continuity loop understandable before the first reading;
- explainable reading hierarchy: make symbolic basis, practical action, context, and boundaries easier to scan;
- Mystic Mirror return messaging: emphasize reality check + private evidence, never prediction accuracy;
- advertising restraint: preserve first-session and core-reflection continuity; no banner/rewarded/core gates;
- competitive QA: compare end-to-end flows, not feature counts;
- accessibility/reduced-motion preservation;
- tests for new copy/behavior contracts where practical.

## Out of scope

- adding broad new divination categories solely to match competitors;
- subscriptions, paid packs, RevenueCat, or purchases;
- remote analytics containing private reading/journal content;
- higher ad frequency as a response to weak retention;
- claims that Mystic Tarot is a proven market leader before live cohort evidence exists.

## Definition of done

A release candidate is ready for owner/device validation when static analysis, full Flutter tests, release web build, Android AAB/audits, and iOS release CI are green, while the UI keeps the core loop understandable and ad interruptions outside the critical reflection path.
