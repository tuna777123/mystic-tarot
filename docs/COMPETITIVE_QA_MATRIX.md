# Mystic Tarot — Competitive Flow QA Matrix

Use this during physical-device validation. Score the same task in Mystic Tarot and the current strongest tarot benchmarks.

| Task | Mystic target | Pass question |
| --- | --- | --- |
| Understand value proposition | <=30s | Can a new user explain the read → tomorrow → pattern loop without help? |
| Complete onboarding | <=90s | Is every step necessary, localized, and visually calm? |
| Start first reading | immediate after onboarding | Is there any dead dashboard state before the first useful action? |
| Reveal cards | premium-feeling | Does motion feel deliberate, readable, and safe with Reduced Motion? |
| Understand interpretation | one scan | Can the user distinguish symbolic basis, position/orientation, practical action, and context? |
| Save reading | clear continuity | Does the user understand that the reading continues tomorrow? |
| Return next day | obvious | Is a due Mystic Mirror the strongest next action? |
| Complete Mirror | <60s target | Does the user record reality without being asked to score prediction accuracy? |
| See patterns | evidence-led | Are repeated cards, emotions, choices, and outcomes connected clearly? |
| Encounter ads | low disruption | Is the core reflection path uninterrupted and consent-respecting? |
| Trust privacy | clear | Can the user find and understand local-first/PIN/biometric controls? |

Do not ship a claim that Mystic is categorically better because it has more features. Prefer fewer, clearer, better-connected flows.
