# Mystic Tarot — English Release Notes

Use this text for the English “What’s New” field in App Store Connect and the English release notes in Google Play Console.

## Release notes — 1.22.3

- New installs now open in English, Turkish, Spanish, French, or Brazilian Portuguese from the device language before onboarding.
- The language selected inside Mystic stays active through card selection, results, profile, settings, and the private app lock.
- Mystic Intelligence continues to build a private seven-day report on the device from saved readings and completed Mystic Mirror check-ins.
- Optional reminder and timezone preparation no longer delays the first usable screen; notification permission is requested only when the user chooses it.
- Device Reduce Motion or Remove Animations settings are respected by the atmospheric background and card-selection motion.
- Additional stability improvements protect the journal, Mystic Mirror, encrypted private transfer, and six-digit app lock.
